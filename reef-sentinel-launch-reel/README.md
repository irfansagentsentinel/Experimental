# Reef Sentinel launch reel

A 36.5-second vertical launch video (1080×1920, 30 fps, H.264 + AAC) for hotels, in the look of the hotel pamphlet: lavender and black, Outfit type, the wave motif.

- `out/reef-sentinel-launch-reel.mp4`: the finished reel, ready to upload.
- `out/cover.png`: a cover frame for the reel.

## Scenes

| Time | Scene |
|---|---|
| 0–4 s | Hook: bookings from everywhere, all in one place |
| 4–8 s | Brand reveal: "World-class hotel software. Support just around the corner." |
| 8–12 s | 30+ properties live, 70+ booking sites, on-site setup and training |
| 12–18 s | Stop double bookings: room chart and booking sites updating together |
| 18–22 s | A faster front desk: check-in, GST bill, daily numbers |
| 22–26 s | Help on WhatsApp and the local team |
| 26–30 s | Coming by April 2027 |
| 30–32 s | Price locked for 3 years |
| 32–36.5 s | Call to action and contact details |

## Changing it

All wording, numbers and timings live in `reel.html`. Open it in a browser to preview in real time, or add `?t=13.2` to the address to freeze on one moment. Each scene sets its start time (`--s`) and each element its delay after that (`--d`).

To render again (needs Node with Playwright, ffmpeg, and Python with numpy and scipy):

```
python3 music.py out/soundtrack.wav   # soundtrack, synthesised from code
node render.cjs                       # frames, then out/reef-sentinel-launch-reel.mp4
```

`node stills.cjs <folder> 7.5 14.6` saves single frames for a quick check.

The soundtrack is generated by `music.py`, so it carries no licence. Mute it in the app if you would rather use other audio.
